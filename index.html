FAQ
What is Mineclowter?

Mineclowter is a free set of Minecraft tools by heyhazik: a seed map, calculators, converters, generators and guides.

Is it free?

Yes. Every tool is free, needs no sign-up and runs in your browser.

Java or Bedrock?

Most tools work for both. The seed map and slime chunk finder follow Java Edition rules; the add-on checker is for Bedrock.
