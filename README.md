# Mineclowter
Free Minecraft tools by **heyhazik**.

- `index.html` - marketplace home
- `tools/` - one HTML file per tool (file name = tool name, `-` = space)
- `icons/` - `name.png` (lowercase) per tool; `main.png` is the site icon

To add a tool: add `tools/My-Tool.html`, then add `["My-Tool","description","badge"]` to a category in `index.html`.
